## Shell Basic-Permission

Part of the project about permissions

- 1-Change the current user 
- 2-Say who is the current user
- 3-Print all the groups of the current user
- 4-Change the owner of a file for an another
- 5-Create an empty file
- 6-Give the execution right for the actual user
- 7-Give all right for the user, the right of read and execute for groups and only the right of read for others
- 8-Give the right to execute for all (users, groups and other)
- 9-Give all right for others but none for groups and user
- 10-Give all rights for user, read and execute for groups and read and write for others
- 11-Give the same rights for all files in a directory
- 12-Give execution right for all files in a directory
- 13-Create a directory with all right for user, read an execute for groups and only execute for other
- 14-Change group owner
- 15-Change the owner and the group
- 16-Change the owner and the groups with a symbolic link
- 16-Change the owner with a condition
