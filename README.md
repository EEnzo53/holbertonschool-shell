## Shell Basics

All folders for Holberton's Project about Shell


A **shell** is a program that takes commands for the keyborard and gives them to the operating system to perform and execute
the difference between shell and terminal is that the shell read and execute the program, it's itself a programme that do programms but terminal is the graphique interface. A Shell prompt is the short sequence of characters displayed on the terminal that signal to the computer that is ready to accept and execute command. All computer have one top-most folder, it's named **ROOT directory** 

## Basics command to use in terminal

- **cd** (change directory): Change the current working directory for another:
*many possibilities of use
 cd /dir/(Normal way)- cd ..(Change for the previous directory(. Current dir, .. previous dir)) - cd - (go to previous working dir that was use)

- **pwd** (print working directory): print the actual path of the working directory:
pwd..... /home/dir1/dir2

- **ls** (list): List all files in the current working directory
*many possibilities of use
ls -l (list all subdir and subfile) ls -la (list all subdir, subfile and even the hide one with more details in the list)

- **rm** (remove) delete files and empty directory
*many possibilities of use
rm -f (Force the file to be deleted without confirmation)

- **mkdir** (make directory) bah make directory :|
- **rmdir** (remove directory) Delete directory
